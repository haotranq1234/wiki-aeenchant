AdvancedEnchantments Wiki
trang giới thiệu plugin bằng tiếng Việt

AdvancedEnchantments là plugin hệ phù phép nâng cao cho Minecraft, cung cấp custom enchant, sách phù phép, souls, scroll, orb, set giáp, vũ khí tùy chỉnh, GUI quản lý item và nhiều công cụ cân bằng gameplay. Trang này tập trung liệt kê đầy đủ 182 enchant kèm tác dụng bằng tiếng Việt để bạn tra cứu nhanh.

Plugin này làm gì?

AE cho phép server xây dựng hệ thống phù phép riêng theo nhóm như SIMPLE, UNIQUE, ELITE, ULTIMATE, LEGENDARY, FABLED. Người chơi có thể dùng sách, dust, white scroll, black scroll, orb và hệ thống souls để nâng cấp item theo phong cách RPG.

Thông tin nhanh

Phiên bản đọc từ file 9.24.10
Số enchant đã nhận diện 182 mục
Trọng tâm Phù phép, item, souls, GUI, set, API

Giới thiệu plugin

AdvancedEnchantments là một hệ custom enchant rất lớn, phù hợp server RPG, SMP nâng cao hoặc server cần cơ chế item phức tạp hơn vanilla.

Tính năng chính

Đây là những phần nổi bật nhất mà plugin đem lại cho server.

Danh sách 182 enchant

Mỗi dòng gồm tên enchant, nhóm, loại vật phẩm áp dụng, kiểu kích hoạt và mô tả tác dụng bằng tiếng Việt.

Mô tả bên dưới là bản diễn giải tiếng Việt từ enchantments.yml để người Việt dễ đọc và tra cứu.

Vật phẩm và hệ thống phụ trợ

AE không chỉ có enchant mà còn có các item đặc biệt, souls, orb, scroll, set giáp, gkit và nhiều hệ thống phụ trợ.

Lệnh chính

Nhóm lệnh quan trọng để mở GUI, cấp item, xem thông tin enchant và quản lý plugin.
