AdvancedEnchantments Wiki
trang giới thiệu plugin bằng tiếng Việt

AdvancedEnchantments là plugin hệ phù phép nâng cao cho Minecraft, tập trung vào custom enchant, sách phù phép, souls, scroll, orb, set giáp, vũ khí tùy chỉnh và GUI quản lý item. Trang này được viết theo kiểu wiki/docs giống cơ chế tài liệu hiện đại, nhưng nội dung và thứ tự được sắp xếp theo plugin AE để người Việt dễ xem hơn.

Plugin này dùng để làm gì?

AE cho phép server tạo ra hệ thống phù phép riêng như Fabled, Legendary, Ultimate, Elite, Simple, kèm theo sách, dust, white scroll, black scroll, slot increaser, soul gem, set bonus, gkit, alchemist, tinkerer và các menu giao diện để người chơi tương tác trực tiếp.

Giới thiệu plugin

AdvancedEnchantments là một hệ thống custom enchant lớn cho server Minecraft, cung cấp enchant đa dạng, menu mở sách, cải tạo item và nhiều công cụ cân bằng game.

Tính năng chính

Tổng hợp những phần làm nên AdvancedEnchantments: hệ enchant, vật phẩm phụ trợ, menu, set, API và các hệ thống có sẵn trong file jar.

Hệ thống phù phép

Trong file enchantments.yml có khoảng 182 phù phép được định nghĩa. Chúng được chia theo group như Simple, Unique, Elite, Ultimate, Legendary và Fabled.

Menus Việt Hóa

Gói menus.zip trong thư mục Việt hóa đã được chuẩn bị sẵn. Các menu chính giúp người chơi tương tác với AE mà không cần nhớ nhiều lệnh.

Vật phẩm và hệ thống phụ trợ

AE không chỉ có enchant mà còn có các item đặc biệt, soul system, orb, scroll, gkit, armor set, mob head và nhiều thứ khác để xây server RPG.

Lệnh chính

Đây là các lệnh nổi bật đã thấy từ file cấu hình, dùng để mở GUI, cấp item, xem thông tin enchant và quản lý hệ thống.

File cấu hình đáng chú ý

AE có nhiều file cấu hình riêng để tách lệnh, menu, groups, locale, armor sets, custom weapons và loot. Phần này giúp bạn hình dung bố cục plugin.

Có thể dùng thêm thư mục locale/vi.yml và menus.zip đã Việt Hóa để triển khai giao diện tiếng Việt cho server nhanh hơn.

Ghi chú Việt Hóa

Trong gói bạn gửi có ghi Việt hóa bởi NguyenDevs. Điều đó có nghĩa là menu, thông báo và nhiều nhãn đã được chuẩn bị để người chơi Việt đọc dễ hơn.

Điểm nổi bật: bản Việt hóa đi kèm menus.zip, locale/vi.yml và các file menu như enchanter.yml, alchemist.yml, tinkerer.yml, gkits.yml, armorSetsPreview.yml, customcommands.yml. Đây là nền rất tốt để làm wiki giới thiệu hoặc hướng dẫn cài đặt cho người chơi.
